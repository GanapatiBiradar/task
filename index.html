Connect your Google Sheet

Noble Print India's tracker reads and writes directly to a Google Sheet through a small Apps Script that lives inside that sheet. No separate server, no API keys to manage.

  1. Open (or create) the Google Sheet you want to use as the order log.
  2. Go to Extensions → Apps Script, delete the placeholder code, and paste in the script from the setup guide below.
  3. Click Deploy → New deployment → Web app. Set "Execute as" to Me and "Who has access" to Anyone.
  4. Copy the deployment URL it gives you and paste it below.

Google Sheet Setup Guide

1. Create the sheet. Make a new Google Sheet. Rename the first tab to Orders and add this header row exactly:

OrderID | Customer | Phone | Item | Quantity | Stage | AssignedTo | Priority | Notes | CreatedAt | UpdatedAt

2. Add the script. In the sheet, open Extensions → Apps Script, clear the default code, paste the script provided separately, and save.

3. Deploy it. Click Deploy → New deployment, choose type Web app, set "Execute as" to Me, and "Who has access" to Anyone. Deploy and authorize when prompted.

4. Connect. Copy the web app URL ending in /exec and paste it into this app's connection settings.

Every new order and every stage or assignment change writes straight back to that Orders tab, so the sheet stays the single source of truth for the whole team.
